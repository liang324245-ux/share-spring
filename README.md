# 共享春天（Share Spring）

一款基于日历的私密照片记录小程序。把生活里的瞬间，悄悄放在某个特定的人那里——不用秒回，不用点赞，不用经营人设。

> 就像在路上看到一朵好看的花，拍下来放到朋友的窗台上，TA 什么时候想看就看。

---

## 📖 项目简介

在社交平台越来越即时、越来越公开的今天，"保持联系"变成了一种负担——朋友圈太公开，一张照片其实只想给一个人看；微信聊天太即时，发了照片对方必须回，不回就尴尬；相册太私密，照片只存在自己手机里，没有合适的渠道分享给特定的人。

**共享春天**填补了这个空白：一款**一对一、异步、以时间为轴**的私密照片空间。用户将生活瞬间按拍摄日期存入日历，与另一个人共同沉淀成一条专属的时间轴，随时可以翻到"去年今天我们看到了什么"。

- 🌱 **不社交**：没有点赞排行、没有公开动态流，一切只在两个人之间
- ⏳ **不即时**：对方随时可以看，没有必须回复的压力
- 🔒 **不公开**：每一段记录都是一对一的私密空间

---

## ✨ 核心功能

- **一对一照片分享**：每一对朋友拥有独立的分享空间，互不干扰
- **日历时间轴**：照片按拍摄日期归档，以日历视图沉浸式回顾
- **暗号加朋友**：用一句只有彼此懂的暗号确认身份，私密且有仪式感；支持多人误撞同一暗号时的双向确认机制
- **轻量互动**：评论、点赞均为自愿触发，默认收起、不打扰
- **已读标志**：知道对方是否看过，但不强制回应
- **好友备注名**：给朋友起一个只有自己能看到的称呼
- **灵活的告别**：删除朋友支持"保留回忆"或"彻底清除"两种方式，尊重每一种关系的结束方式
- **账号注销**：7 天冷静期机制，期间可随时恢复；彻底注销后仍为朋友保留曾经的记录
- **订阅提醒**：新照片到达时，可选择接收微信服务通知

## 🏗️ 技术架构

- **前端**：微信小程序原生框架（WXML / WXSS / JS）
- **后端**：微信云开发（云函数 + 云数据库 + 云存储）
- **云环境**：`cloudbase-d3g00thv5d1e1d96e`

### 云函数一览

| 云函数 | 类型 | 功能 |
|---|---|---|
| `login` | 普通 | 登录 / 建档 / 账号状态流转 |
| `createInvite` | 普通 | 发起暗号邀请 |
| `matchInvite` | 普通 | 暗号匹配（唯一直连 / 撞车进互认） |
| `getApplicants` | 普通 | 发起者查看撞号申请者 |
| `pickApplicant` | 普通 | 发起者选择申请者 |
| `getMyPickers` | 普通 | 接收者查看选中自己的发起者 |
| `confirmFriend` | 普通 | 接收者双向确认，正式连接 |
| `updateProfile` | 普通 | 更新昵称 / 头像 / 通知偏好 |
| `getPhotoUrls` | 普通 | 批量转换云存储临时链接 |
| `markRead` | 普通 | 标记照片已读 |
| `addComment` | 普通 | 发表评论 |
| `toggleLike` | 普通 | 点赞 / 取消点赞 |
| `deleteFriend` | 普通 | 删除好友（保留式 / 彻底清除） |
| `deactivateAccount` | 普通 | 申请账号注销 |
| `reactivateAccount` | 普通 | 冷静期内恢复账号 |
| `setRemark` | 普通 | 设置好友备注名 |
| `sendPhotoReminder` | 普通 | 新照片订阅消息推送 |
| `cleanExpired` | **定时** | 每日扫描处理过期删除关系与到期注销账号 |

### 数据结构（云数据库）

- `users`：用户资料（昵称、头像、账号状态、通知偏好）
- `friendships`：好友关系（暗号、状态、备注名、删除记录）
- `photos`：照片记录（拍摄日期、上传时间、已读状态）
- `comments`：评论
- `likes`：点赞
- `applications` / `picks`：暗号撞车时的多对多互认申请记录

## 🔐 隐私与合规

- 服务类目：`工具 - 日历`、`工具 - 图片处理`
- 已配置《用户隐私保护指引》，明确收集信息用途（用户昵称头像、用户选择的照片）
- 账号注销支持 7 天冷静期，期间数据不做任何清除；到期后清空个人资料并对好友保留式断开，历史记录不受影响
